# profile_data/

Single home for the **profiling + simulator data** (kernel grids, measured benchmarks,
prediction outputs). Code lives in `profiling/` and `simulator/`; **data lives here.**

## Layout

| dir | tracked? | contents |
|---|---|---|
| `kernels/` | **committed** | Curated kernel-grid INPUTS the predictor reads: forward-pass GEMM/attention (`forward_pass/`, `gemm/`, `flash_attn/`), `fa3_prefill_H100.csv`, prefill grids (`prefill_profile_H100*.csv`, incl. the tp2 `prefill_profile_H100x2.csv`), `roofline_params_H100_llama31_8b.json`, `serving_calibration*`, `kernel_composition/`, `models/`, `elementwise/`. Small, canonical, versioned. |
| `results/` | gitignored | Regenerable measured grids + benchmark dumps the pipeline reads, and the predictor OUTPUTS: decode grids (`decode_kernel_trace_*_wide_summary.csv`, `decode_profile_H100_large_*.csv`, `decode_profile_H100x2_*.csv`), `cached_prefill_v3_H100.csv`, `cached_prefill_batch_ttft_H100.csv`, `benchmark_per_request_*` / `benchmark_turns_*`, and `llama31_8b_h100_*_predictions.csv` / `*_report.md`. |
| `_archive/` | gitignored | Stale scratch from the old `profiling/results/` (engine traces, `fluid_wave_*`, `vllm_engine_step_trace_*`, `serving_parity_ladder_*`, old validation/trajectory CSVs). Not read by live code; kept for reference. |

## Regenerating

- Kernel/grid measurements (need a GPU; see `profiling/docs/h100_setup.md`):
  - decode grid — `profiling/profile/vllm/cuda_events/decode_steps.py --output profile_data/results/<name>.csv [--tensor-parallel-size N]`
  - prefill grid — `profiling/profile/vllm/sweep/prefill_steps.py --output profile_data/kernels/<name>.csv [--tensor-parallel-size N]`
  - cached-prefill batch TTFT — `profiling/profile/vllm/cached_prefill_batch_ttft.py`
- Predictions / dashboard JSON (no GPU): `profiling/process/predictors/predict_llama31_8b_h100_tpot_with_engine_steps.py`
  then `python3 -m profiling.process.emitters.augment_simulator_predictions_with_{kernel,ttft}` and
  `build_tp2_simulator_rows`; validate with `profiling.process.predictors.validate_{kernel_tpot,ttft}`.

## Data deliberately left in place (not under profile_data/)

- **`inference-benchmark/data/distributions/`** — workload session-length / context-scale
  distributions (survival + `*_realized.json`). They are *workload spec*, coupled to the benchmark
  generator and read via `simulator/ramp_tpot.py::DIST_DIR`, regenerated by
  `profiling/process/extractors/build_realized_session_distributions.py`.
- **`inference-benchmark/dashboard/public/*.json`** — dashboard-served data. `data*.json` come from
  Cloudflare R2 in prod; `simulator-predictions.json` is fetched at runtime from the dashboard
  static root (`/`). These stay in `public/` (deploy contract).
- **`/mnt/100g/agent-bench/results/synthetic_distributional/`** — the raw multi-turn benchmark
  results (per-request JSON) the augmenters read for measured `*_meas`. External mount, not in-repo.
