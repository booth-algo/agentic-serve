# CLAUDE.md
Codebase Rules - For both AI agents and humans

### General

- Do not suddenly remove an entire part of my code, or an entire function, without asking.
- Do not ask questions and immediately assume I'm telling you to automatically work on it.
- The key crucial part is that we're not doing long automatic agentic workflows - you need to stop, ask questions, think about what the instructions mean, come back with a suggestion, and only work on things modularly and with much human input.

### Python

- Do not add `from __future__ import annotations` by default.
- Start the file with a simple comment like `# <dir>/<dir>/<filename>`
