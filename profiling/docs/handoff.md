## 1. Status / headline

The dashboard's `simulator-predictions.json` is built by **ONE config-driven, headline-only
generator**: `python3 -m profiling.process.build_simulator_rows`. A `CONFIGS` table (one row per
GPU/TP) drives it; per config × (profile, conc) it reads per-turn medians from the `/mnt/100g`
benchmark and runs the headline predictors. Adding a GPU = adding a `CONFIGS` row.

Canonical gates (turn-level mean APE = the dashboard MAPE number), validators below:

| config | TPOT | swe-plateau | TTFT | E2EL |
|---|--:|--:|--:|--:|
| **H100 (tp1)** | **15.9%** | 8.8% | **33.0%** | **19.6%** |
| H100x2 (tp2) | 53.8% ⚠️ | — | 43.3% ⚠️ | 35.4% ⚠️ |

`python3 -m profiling.process.validate_tpot` / `validate_ttft`. 148 tests pass; dashboard builds.

Standing discipline: **no fitted constants without physical basis** (kernels/grids/KV-pool measured;
survival + context-scale are measured workload distributions). MAPE = mean per-turn APE; **judge the
TTFT climb by WAPE + signed bias, not MAPE** (turn-0 noise dominates MAPE).

## 2. The three predictors

- **TPOT (headline `tpot_pred`)** — kernel-composed: `simulator/kernel_tpot.py::predict_cell_tpot`,
  `kernel_step = decode_step_ms(B_eff,ctx)` from the measured decode grid (`kernel_step_cost.py`) ×
  a pressure-driven amplifier toward a saturated ITL ceiling. KV pool + bandwidth from
  `RooflineParams` (`closed_form_tpot.py` + `profile_data/kernels/roofline_params_H100_llama31_8b.json`).
- **TTFT (headline `ttft_pred`)** — forward closed-loop queue sim `simulator/ttft_queue_sim.py::
  predict_cell_ttft_qsim`: barrier round-robin arrivals + vLLM v1 chunked-prefill budget + block-level
  prefix cache with **two-tier RECOMPUTE preemption** (evict idle herd residents under genuine
  over-subscription → MISS re-prefill = the climb). Cohort = C sessions from the profile's **realized
  survival**, each scaled by a measured **per-session context-size factor** (small sessions stay
  resident=hits, large minority preempted → median stays a hit near the sharp KV cliff = the osworld
  saturate-recover). **This session's big fix:** before it, the sim silently deadlocked at high conc
  and fell back to a shallow static formula → the climb under-tracked. See
  [[ttft-qsim-silent-fallback-highconc]].
- **E2EL (`e2el_pred`)** — composed: `ttft_pred + output_tokens · tpot_pred`. Decode-dominated, tracks well.

Cohort distributions: `ramp_tpot.py PROFILE_DIST` → `inference-benchmark/data/distributions/
<profile>_realized.json` (turn-count histogram + `context_scale_quantiles`), regenerated by
`profiling/process/build_realized_session_distributions.py`.

## 3. tp2 (H100x2) — first cut, KNOWN-INCOMPLETE

Ground truth is the real `h100_Llama-3.1-8B_tp2_vllm` benchmark. Measured on 2×H100 (GPU 4,5): KV
pool **62416 blocks** (998,656 tokens), decode grid **~0.70× tp1** (`profile_data/results/
decode_profile_H100x2_*.csv`), prefill grid 0.39–0.82× tp1 (`profile_data/kernels/prefill_profile_H100x2.csv`).
The generator swaps in the tp2 decode grid + KV pool. **Still wrong:** (a) TPOT over-predicts (~54%)
because the generator keeps tp1 `peak_bw_bytes_per_s` (so the analytic OOM-corner fill of the sparse
tp2 decode grid uses tp1 bandwidth) AND the tp1 saturation ceiling (~240 ms); (b) TTFT prefill law is
still tp1-anchored. Fixes (offline, no GPU): override `peak_bw` for 2-GPU + re-anchor the TPOT ceiling
(`kernel_tpot.py`); re-anchor the serving prefill FLOOR/NEW/HOST on tp2 c1 cells (`ttft_queue_sim.py`).
See [[simulator-dashboard-tp2-firstcut]].

## 4. Where everything lives

- **Code:** `simulator/` (the predictors + queue sim) and `profiling/` (profilers in `profile/`,
  pipeline in `process/`). `profiling/process/` is FLAT now: `build_simulator_rows.py`,
  `validate_{tpot,ttft}.py`, `build_realized_session_distributions.py`, `extract_benchmark_per_request.py`,
  `update_tpot_fit_with_kernel.py`; retired scripts in `process/_legacy/`. See [[simulator-rows-pipeline-unified]].
- **Data:** `profile_data/` (root). `kernels/` = committed curated grids; `results/` = gitignored
  measured grids + outputs; `_archive/` = gitignored scratch. `profile_data/README.md` is the index.
  Workload distributions stay in `inference-benchmark/data/distributions/`. See [[profile-data-layout]].
- **Ground truth (external mount):** `/mnt/100g/agent-bench/results/synthetic_distributional/
  h100_Llama-3.1-8B_tp{1,2}_vllm/<profile>_conc<C>.json` → `per_request[]` medians per turn.
- **Dashboard:** `inference-benchmark/dashboard/src/components/ServingPredictionsPage.tsx`. Simulator
  page self-selects **model + GPU dropdowns** + TTFT/TPOT/E2EL MAPE badges; the per-turn chart marks
  the line that feeds the table with **★** (now always the single `tpot_pred`/`ttft_pred`). JSON is
  fetched from `public/` (gitignored, regenerated). H100 profiling: `profiling/docs/h100_setup.md`
  (ssh `h100`, GPU index via CUDA_VISIBLE_DEVICES, run from `/data48/kevinlau/tmp/cpbatch_run`).

are measured. Consistent stats = the validator's turn-level mean APE = the dashboard badge.
